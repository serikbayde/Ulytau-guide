# pitch/ — «Ұлытау гид» презентациясы (Pizza Pitch, 14 қараша)

| Файл | Не үшін |
|---|---|
| `Ulytau_Gid_Pitch.pptx` | Негізгі презентация, 14 слайд, 16:9, сөйлеу уақыты дәл 5:00, заметкаларда сөйлеу мәтіні бар |
| `Ulytau_Gid_Pitch.pdf` | Сол презентацияның PDF нұсқасы. Залдағы компьютерде Montserrat/Inter қаріптері болмаса, осыны көрсетіңіз |
| `SPEAKER_SCRIPT_KZ.md` | Бүкіл сөйлеу мәтіні: слайд бойынша, уақыты және спикері көрсетілген |
| `JURY_QA.md` | Қазылардың 10 ықтимал сұрағы және жауаптары |
| `PITCH_SOURCES.md` | Әр цифрдың дереккөзі |
| `IMAGE_CREDITS.md` | Фото авторлары мен лицензиялары |
| `KZ_CHECK.md` | Тілді жетік білетін адам тексеретін тұстар |
| `assets/` | Фото, телефон макеттері, иконкалар, QR, өрнек |
| `build/` | Барлығын қайта жинайтын скрипттер |

Қайта жинау (мысалы, плейсхолдерлерді толтырғаннан кейін): мәтінді `build/build_deck.py` (слайдтар) немесе
`build/notes_kk.json` (заметкалар) ішінен түзетіңіз, сосын:

```bash
pip install python-pptx qrcode pillow
```

```bash
pitch/build/render.sh /tmp/render
```

Скрипт PPTX пен PDF-ті қайта жасайды және тексеру үшін PNG шығарады. Фото қиындыларын қайта жасау үшін
(`build/prep_photos.py`) Wikimedia-дағы түпнұсқаларды қайта жүктеу керек, сілтемелері `IMAGE_CREDITS.md`-де.
