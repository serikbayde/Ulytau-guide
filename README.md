# 🏔 «Ұлытау гид» — Telegram-бот для туристов

Гид по области Ұлытау (Казахстан). Бот показывает сакральные, исторические и природные места, предлагает
готовые маршруты, а AI-гид отвечает на вопросы **только по проверенным данным**. Языки интерфейса:
қазақша, русский, English.

Проект подготовлен для конкурса стартапов **Pizza Pitch** (демо 14 ноября). Бот: [@yelulytaubot](https://t.me/yelulytaubot).

## Возможности

| Кнопка | Что делает |
|--------|-----------|
| `/start` | выбор языка, затем главное меню |
| 📍 Места | 14 мест кнопками; в карточке описание, как добраться, советы, **«Открыть на карте»** (Google Maps по координатам) и **«Источники»** |
| 🗺 Маршруты | 3 маршрута (1 день, 2 дня, выходные) с планом по времени; из маршрута можно открыть карточку любого места |
| 🤖 Спросить гида | вопрос свободным текстом. Gemini отвечает на языке пользователя и **только** по `places.json` и `routes.json`. Если ответа в данных нет, честно говорит «не знаю» |
| 🌐 Язык | смена языка в любой момент |

Если нет ключа Gemini или сервис недоступен, бот не падает: он пишет понятное сообщение, а «Места» и «Маршруты»
продолжают работать.

## Быстрый старт (локально)

Нужен Python 3.11 или новее.

```bash
cd ulytau_guide
```

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env
```

Откройте `.env` и впишите:
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather);
- `GEMINI_API_KEY` — ключ из [Google AI Studio](https://aistudio.google.com/apikey) (бесплатный тариф).

Запуск:

```bash
python bot.py
```

В логе должно появиться `Подключено к Telegram как @<имя_бота>` и `Бот запущен`. Остановка — `Ctrl+C`.

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|-----------|-------------|---------|
| `BOT_TOKEN` | — | токен бота (обязательно) |
| `GEMINI_API_KEY` | пусто | ключ Gemini; без него AI-гид отвечает «недоступен» |
| `GEMINI_MODEL` | `gemini-3.5-flash` | основная модель |
| `GEMINI_FALLBACK_MODELS` | `gemini-3.5-flash-lite,gemini-3.1-flash-lite` | запасные модели через запятую |
| `GEMINI_TIMEOUT` | `40` | таймаут запроса к Gemini, секунды |
| `USERS_FILE` | `var/users.json` | где хранить выбранные языки |

> **Лимиты бесплатного тарифа Gemini.** Проверка 9 ноября 2026 показала лимит **5 запросов в минуту на каждую
> модель**. Поэтому бот при ошибке или лимите пробует запасные модели (у каждой своя квота) и час кэширует ответы
> на одинаковые вопросы. Модели `gemini-2.5-*` для новых ключей уже недоступны.

## Как устроен AI-гид (для жюри)

1. При вопросе бот собирает **системный промпт**: строгие правила и вся база знаний из `places.json` и `routes.json`
   (описания на языке пользователя, названия мест на всех трёх языках).
2. Правила: отвечать только по базе, ничего не выдумывать, отвечать на языке пользователя, называть легенды
   легендами, сообщать о непроверенных данных. Если ответа в базе нет, модель отвечает фразой
   «Извините, в моих данных нет информации об этом — не знаю».
3. `temperature=0.2`: меньше «фантазии», больше точности.
4. Ошибки сети, лимиты и таймауты перехватываются, и пользователь видит понятное сообщение.
5. Ответ отправляется простым текстом, а Markdown модели очищается, поэтому разметка Telegram не ломается.

Это подход RAG («retrieval-augmented generation») в самом простом виде: база маленькая (14 мест), поэтому она
целиком помещается в промпт.

## Тесты

```bash
pip install -r requirements-dev.txt
```

```bash
pytest
```

Что проверяется (65 тестов):
- `test_data.py` — JSON загружается; у каждого места все поля на 3 языках, координаты в пределах области, источники-URL,
  флаг `verified`; казахские тексты содержат казахские буквы; маршруты ссылаются на существующие места;
- `test_locales.py` — все тексты интерфейса есть на 3 языках с одинаковыми плейсхолдерами;
- `test_handlers.py` — хэндлеры целиком через Dispatcher с фейковой сессией Telegram: /start, выбор языка, места,
  карта, источники, маршруты, навигация назад, AI (успех, нет ключа, ошибка), лимит частоты, длина сообщений < 4096;
- `test_ai_guide.py` — промпт содержит все данные, запасные модели, таймаут, кэш, очистка Markdown;
- `test_startup.py` — импорт и сборка бота без ключей, выход с понятной ошибкой при пустом или неверном токене,
  ожидание сети при старте, установка команд и описания бота на 3 языках.

Живые тесты с настоящим Gemini (тратят 3 запроса квоты):

```bash
RUN_LIVE_GEMINI=1 pytest -m live -s
```

## Как обновить данные

Отредактируйте `data/places.json` или `data/routes.json` и перезапустите бота. Тесты (`pytest`) проверят, что ничего
не сломалось: все языки на месте, координаты в пределах области, источники указаны.
